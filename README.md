# 🌱 효명고등학교 전문적 학습공동체(전학공) 방명록

함께 배우고 성장하는 효명고등학교 선생님들을 위한 실시간 디지털 방명록 웹 애플리케이션입니다.

## ✨ 주요 기능
- **학교 전용 로그인 보안**: 효명고 교직원 구글 계정(`@hmh.or.kr`)으로만 로그인 가능
- **실시간 방명록 피드**: 새로고침 없이 동료 선생님들의 메시지가 즉시 화면에 업데이트 (Firebase Firestore 연동)
- **따뜻하고 모던한 UI**: 숲빛 에메랄드 테마의 아늑한 디자인 및 모바일 스마트폰 완벽 지원
- **개인정보 보호**: 불필요한 민감정보(전화번호, 주민번호 등) 수집 없이 안심하고 사용 가능

## 📁 프로젝트 파일 구조
- `index.html`: 메인 웹 화면
- `style.css`: 반응형 디자인 및 스타일시트
- `app.js`: 로그인 인증 및 실시간 방명록 동기화 로직
- `PRD.md`: 요구사항 명세 및 추진 로드맵
- `README.md`: 프로젝트 안내서

## 🚀 로컬 실행 방법
1. Visual Studio Code / Antigravity 우측 하단의 **[Go Live]** 버튼 클릭
2. 또는 `index.html` 파일을 우클릭한 후 **'Open with Live Server'** 선택
